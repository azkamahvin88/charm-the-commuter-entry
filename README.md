One weather-forecast line, max 140 characters, for a city that doesn't
exist — written to make a bored commuter smile on the way to work.

## The entry

> In Snoozeburg, expect scattered naps with a 90% chance of finding a seat — the clouds are snoring, so bring coffee.

115 characters. Snoozeburg is a sleepy city that doesn't exist; the forecast
promises scattered naps and a 90% chance of the commuter's daily lottery win
— a seat on the bus — while the clouds snore along and coffee does the rest.

See [CANDIDATES.md](CANDIDATES.md) for the 12 brainstormed lines, their
scores against the judge's brief, and why this one won.

## Run

```bash
OUTPUT_DIR=/tmp/charm-commuter-test node main.ts
# writes /tmp/charm-commuter-test/entry.txt
```

Node 22+ (stdlib only, no dependencies). The program fails loudly if the
line is empty, longer than 140 characters (counted in code points), or
contains a newline.
